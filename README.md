# promptsquad-assets

Published image assets for the PromptSquad newsletter. This repo exists so Beehiiv can fetch images by URL.

Layout: `covers/YYYY-MM-DD/banner.png` (1200x549 email banner) and `covers/YYYY-MM-DD/thumb.png` (1024x1024 post thumbnail).

Raw URL pattern: `https://raw.githubusercontent.com/seabatt/promptsquad-assets/main/covers/YYYY-MM-DD/banner.png`

Nothing lands here before it is meant to be seen. Written by the daily AI TL;DR job; see PromptSquad/Brand/character/README.md.
